# Bug reports from play-testing (free-roam mode)

20 bugs found while play-testing free-roam skating. Cop-chase mode was not tested. Each file is a ready-to-file GitHub issue: the first line is the title and the rest is the body. Each one covers what happens, how it was reproduced, where the code is, the likely cause and a suggested fix.

To file them all as issues (labelled `bug`):

```sh
gh auth login            # once
bash docs/bugs/create_issues.sh
```

Line numbers refer to the code at the time of testing.
